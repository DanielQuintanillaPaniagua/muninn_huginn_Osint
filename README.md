## 🪶 The Legend

> *Huginn and Muninn fly each day over the spacious earth. I fear for Huginn, that he come not back, yet more anxious am I for Muninn.* — Odin, Grímnismál

In Norse mythology, **Huginn** (Thought) and **Muninn** (Memory) are the two ravens of Odin. They travel across the entire world every day, gathering information and whispering it into his ears.

This tool follows the same concept — silently traversing the web, collecting publicly available intelligence from multiple platforms and reporting it back to you.

## ✨ Features

```bash
✓ Username search across 10+ platforms
✓ Interactive command-line menu
✓ Colored terminal output
✓ Automated profile checking via HTTP requests
✓ Search single platform or all at once
✓ Zero dependencies beyond standard Linux tools
```

## 🚀 Installation

```bash
# Clone the repository
git clone https://github.com/DanielQuintanillaPaniagua/muninn_huginn_Osint.git

# Enter the directory
cd muninn_huginn_Osint

# Grant execution permission
chmod +x muninn_huginn.sh

# Launch
./muninn_huginn.sh
```

**Requirements:** Linux / Unix · Bash · curl · Internet connection

> Most Linux distributions already include these tools by default. No additional installation needed.

---

## 📖 Usage

After launching, the tool displays an interactive menu:

```
╔═══════════════════════════════════════╗
║     MUNINN HUGINN — OSINT TOOL        ║
║     Username Reconnaissance           ║
╠═══════════════════════════════════════╣
║  1) Search LinkedIn                   ║
║  2) Search YouTube                    ║
║  3) Search Facebook                   ║
║  4) Search Instagram                  ║
║  5) Search Twitter / X                ║
║  6) Search GitHub                     ║
║  7) Search all platforms              ║
║  8) Exit                              ║
╚═══════════════════════════════════════╝

Enter option: _
```

Choose a platform (or option **7** to scan all at once), then enter the username to investigate. The script will attempt to verify whether that profile exists via HTTP requests.
